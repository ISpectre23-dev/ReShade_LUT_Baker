# Monster Hunter Wilds LUT format

The Wilds export writes one fixed profile: TEX version 241106027, 33 × 33 × 33, RGBA16F (16-bit float per channel), compressed with GDeflate. It matches the map and event LUTs of Wilds 1.42.0.2.

Wilds support is experimental: in-game results are not reliable yet.

The game also has a 32³ 8-bit neutral LUT with a different layout. This export does not write that one, and a Rise file is not compatible either.

## File layout

A 56-byte header, an 8-byte image header and the compressed data. All fields are little-endian.

| Offset | Field | Value |
| --- | --- | --- |
| 0 | Signature | `TEX\0` |
| 4 | Version, uint32 | 241106027 |
| 8 / 10 / 12 | Width / height / depth, uint16 | 33 / 33 / 33 |
| 14 / 15 | Image count / mip header size | 1 / 16 |
| 16 | DXGI format, uint32 | 10, `R16G16B16A16_FLOAT` |
| 20 | Swizzle control, int32 | -1 |
| 24 | Cubemap marker, uint32 | 0 |
| 28–39 | Control bytes | `00 07 00 00`, then eight zeros |
| 40 | Mip offset, uint64 | 56 |
| 48 | Row pitch, uint32 | 512 |
| 52 | Size of one depth slice, uint32 | 16,896 |
| 56 | Compressed size, uint32 | Size of the GDeflate stream |
| 60 | Image offset, uint32 | 0 |
| 64 | Image data | GDeflate stream, starts with `04 FB` |

The file size varies with compression. The decompressed data is always 557,568 bytes.

## Sample order

Red changes fastest, then green, then blue. Each row holds 33 pixels of 8 bytes, followed by 248 zero bytes of padding. Alpha is always 1.0.

```text
sample_index = (blue * 33 + green) * 33 + red
data_offset  = (blue * 33 + green) * 512 + red * 8
pixel        = half(R), half(G), half(B), half(1.0)
```

## Conversion

Each RGB value is rounded to the nearest 16-bit float. Values from -65504 to 65504 are kept, including negatives and values above 1. NaN, infinity and anything outside that range are rejected. No clamping or gamma conversion is applied.

GDeflate is lossless. Before writing, the add-on decompresses the result and compares it byte for byte with the original data.

## Color domain

Wilds grades in a logarithmic color domain: the game encodes the color before looking it up in the LUT and decodes the result afterward. The export does not convert to that domain, so the in-game look may differ from your ReShade grading.
